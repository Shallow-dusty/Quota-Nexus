## 使用规则

1. 新设计变更使用下一个连续编号 `PROPOSAL-003.md`。
2. 一方提交，另一方逐条审计；驳回必须写明理由。
3. 只有双方同意的内容才进入 `DESIGN.md`。
4. 已闭环提案不删除、不搬入普通归档；它们承担设计决策溯源职责。
5. 当前项目状态写入根目录 `STATUS.md`，不要在提案中维护实时状态。
