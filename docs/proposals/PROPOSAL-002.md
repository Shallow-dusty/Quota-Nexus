### P-023 Phase 0 探针增加绝对用量取证义务

- **目标章节**：§17 Phase 0 交付清单、`docs/provider-contracts/`
- **状态**：pending
- **现状与问题**：P-008（`QuotaWindow` 绝对用量字段）因"单位、分母和跨窗口语义未经
  Phase 0 证实"被驳回，提案方已接受该结论。但 v0.2.0 §17 的探针交付清单（响应结构
  记录、字段映射、认证验证、重置语义、代理行为）不含绝对用量观测项——探针仅验证
  百分比即可通过 Phase 0 验收，绝对用量的证据将永远不会被收集，P-008 事实上被
  永久关闭而非"推迟"。
- **提议修改**：§17 Phase 0 交付清单增加一条：

  > 若上游响应包含绝对用量字段（已用量/总量数值），记录其字段名、单位、分母语义
  > （如 credits / requests / tokens）、以及 limit 是否随套餐或周期变化，写入
  > `docs/provider-contracts/`；该记录是恢复 P-008（绝对用量字段）提案的证据前提。
  > 若三家均不返回绝对用量，则明确记录"P-008 永久关闭"。

- **理由**：这是对已达成一致的驳回结论的执行补全，而非重开争议——驳回理由是
  "未经 Phase 0 证实"，那就应保证 Phase 0 真的会去取证。成本为探针阶段的一段
  记录代码；收益是 P-008 的复活决策（或永久关闭决策）将基于事实而非假设，
  与项目"探针优先"的方法论一致。
- **依赖**：无。
- **对"过度设计"预设反驳的预案**：本条目不要求实现任何解析或存储逻辑，只要求
  探针**记录**；记录格式即 §14.2 既有的脱敏 fixture 流程，无新增基础设施。
